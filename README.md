# 烧鸟店超级管理员工作区

这里是烧鸟店的统一经营管理系统。它不仅管理内容，还管理人、事、钱、货、门店、公域、私域和经营决策。

## 从这里开始

直接告诉管理员目标，例如：

- “从烧鸟成品素材里做 3 篇小红书发布包。”
- “整理本周抖音选题，重点推湖边晚风和炭火烧鸟。”
- “盘点其他待判断素材，先给迁移清单，不要移动文件。”
- “给今天的内容做发布前检查。”
- “把已发布内容整理成复盘台账。”
- “把这周所有事项按负责人、截止日期和风险整理出来。”
- “录入本月收入支出，生成预算与实际差异。”
- “根据客流安排下周排班，并标出缺口。”
- “盘点库存和损耗，找出成本异常。”

## 管理系统地图

| 位置 | 用途 | 管理规则 |
|---|---|---|
| `00_经营驾驶舱/` | 目标、指标、周报月报、决策清单 | 老板总览入口 |
| `01_人员与组织/` | 员工、排班、岗位、培训、绩效 | 隐私数据受控 |
| `02_项目与事项/` | 项目、任务、负责人、期限、风险 | PM 管理中心 |
| `03_财务管理/` | 收支、预算、现金流、毛利、对账 | 原始凭证不覆盖 |
| `04_门店运营/` | 装修、营业、服务、卫生、设备、菜单 | 现场执行中心 |
| `05_供应链与库存/` | 供应商、采购、库存、损耗 | 连接食材成本 |
| `06_公域运营/` | 素材、内容、发布、平台数据 | 抖音与小红书闭环 |
| `07_私域与会员/` | 微信、社群、会员、反馈、复购 | 保护顾客隐私 |
| `08_品牌与店铺资料/` | 品牌、视觉、地址、营业时间、证照 | 对外事实唯一来源 |
| `09_系统与自动化/` | 工具、脚本、技能、接口 | 修改后必须验证 |
| `90_待归档/` | 暂时无法判断的资料 | 定期清空 |
| `99_系统临时区/` | 测试、缓存、预览 | 可再生成，不作正式依据 |

## 公域运营闭环

```text
06_公域运营/
├── 01_原始素材/
├── 02_选题与计划/
├── 03_内容制作/
├── 04_发布成品/
│   └── YYYY-MM-DD/平台/序号_主题/
└── 05_数据与复盘/
```

根目录现有文件属于旧结构。暂时保留是为了避免破坏脚本路径；后续根据迁移清单进入上述管理系统。

## 管理员边界

管理员可以直接分析、策划、生成文案和整理成品；删除或批量移动文件、公开发布、付费、登录外部账号、联系顾客或供应商前，必须得到老板确认。
