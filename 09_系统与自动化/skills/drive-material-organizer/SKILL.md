# 每日素材整理

## 每次定时运行

这是一个完整的每日整理技能；定时任务调用本技能，去重和质量检测属于每次运行的必要步骤，不是独立任务。

1. 检查北京时间与剩余窗口，读取台账和检查点，扫描新文件、版本变化和未完成项；输出目录中的已整理文件仅用于库存比较与验证，不再次入队。
2. 读取图片实际画面、视频取帧或所需片段，按下表判断内容分类和实际机位；无法读取的保留待审状态。
3. 对可读取原件执行去重和质量检测，与已检测库存跨日期比较。记录完全重复、相似候选、技术问题和视觉选片等级；缺少检测条件的明确记待检测，不宣称合格。
4. 对分类及批次日期明确的文件分配稳定序号，保存移动改名计划，执行已授权的原件移动与命名，再回读名称、父目录及大小。重复或低质候选仍保留，不能自动删除；质量待复审不妨碍已确认分类，但必须保留问题标记。
5. 更新同一台账与状态，汇总本轮新增、分类、重复候选、质量等级、待检测/待审及失败数量。到截止时间保存未完成项，次日继续；没有有意义变化时不通知。

## 图片和视频审阅

- 文件名与日期只帮助检索，不作为内容分类证据。图片须查看实际画面。使用连接器返回的认证文件引用/本地路径，不拼接公共下载链接或输出凭据。
- 视频须下载可读取原件后取帧，短视频至少看开头、中间、结尾；长视频增加均匀取帧，发现场景变化补看边界。使用可用的 ffmpeg 等工具，缓存放 `99_系统临时区/drive-material-organizer/`，不改原件。
- 本项目 `.venv/bin/python` 已安装 Pillow、imageio-ffmpeg，可运行 `scripts/preview_media.py` 从台账已登记且已下载的原件生成带文件序号、时间码的图片联览及视频取帧图。缓存文件名为 Drive ID 加原后缀，文件大小与元数据一致才处理。联览只是审阅辅助，必须实际查看生成图才记已审阅。原件缺失时脚本跳过，不等于审核成功。
- 有动作、对白或多场景判断需求时播放对应片段或听实际音频；只看抽帧时明确记为“抽帧审阅”，不称完整观看。记录可用片段时间码及其分类，一条视频可有多个次类。
- 若连接器文件引用无法在本地读取，标记“待视觉审阅”并说明缺少何种能力，不根据名字补填分类。已枚举、已看图、已抽帧、已完整观看是不同状态。
- 素材价值记“优先候选／普通候选／需复审／无法判断”；模糊、过暗、遮挡、抖动、重复只是问题标签。人物授权未知记“发布前核实”，不识别人名，不发布顾客画面。

## 去重与质量检测

- 每次运行处理新增或版本变化素材时，在移动改名前检测已缓存原件；已有有效检测结果可复用。先进入工作区，运行 `.venv/bin/python 09_系统与自动化/skills/drive-material-organizer/scripts/audit_media.py`；老板授权立即手动运行时加 `--manual`。依赖 Pillow、imageio-ffmpeg、numpy。脚本不改原件、不删文件，检测结果集中写入同一 `state.json`，人工结论追加或更新主台账的“去重与质量检测”区，不另建重复报告。跨批次比较依赖已有检测指纹；没有指纹的旧库存标记覆盖不足，不宣称已全库去重。
- SHA-256一致才是本轮完全重复的文件；图片感知哈希只找相似候选，同场景视频只标记重拍候选，不能据此判完全重复。检测应跨批次与已有库存比较；文件ID仅避免重复入队，不能代替内容去重。
- 质量分三层：技术可读性（图片实际解码，视频完整解码）、机器筛查（尺寸、时长、按每秒4帧取样的亮度/暗部/高光/边缘指标）、视觉选片（主体清晰、构图、遮挡、方向、抖动及可用片段）。完整解码不是完整观看；抽帧指标不能证明所有画面、声音和动作都合格。
- 夜景、夕阳、背景虚化、镜头移动会影响指标，数字只提示复审，不单凭阈值判废片。小于720短边或短于2秒是提示，不是自动剔除标准；横侧画面可修正方向，短片可作插镜。推荐等级使用“优先使用／处理后使用／备用／建议不选用”，与客观检测分开，说明具体理由和候选时间码。
- 相似组列出逐份链接、推荐保留/优先使用哪份、其余为何备用，原件仍留分类目录。老板此次请求授权检测及去重标记，未授权实际删除。任何实际删除须列出准确文件ID、路径及对应保留文件，获得明确确认后才执行；不得自动删除完全重复、相似或低质候选，也不移动进垃圾箱。
