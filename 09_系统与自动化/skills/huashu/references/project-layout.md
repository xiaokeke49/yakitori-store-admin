## 串品主数据

`商品数据/sku.csv` 推荐字段：

```csv
sku_id,name,state,category,unit_cost,sale_price,source_file,cutout_file,available,updated_at
```

- `state` 只能是 `raw` 或 `cooked`。
- 原图与透明图必须通过 `sku_id` 对应，不能只靠相似文件名猜测。
- `unit_cost` 与 `sale_price` 分开；未确认留空。
- `available` 表示当前是否允许进入可售套餐，不等同于长期库存。

## 每次任务清单

每个花束任务记录：任务编号、目标人群/节日、模式、串品 SKU 与数量、包装、装饰、底座、背景、输出平台、来源文件、成本、售价、物理验证、审核结论、发布链接。

原文件不改名、不移动也可以工作；先建立索引。以后新增素材时，拍摄正面、左右 30–45 度、统一灰卡或中性背景、自然光与比例参照，并为同一 SKU 的生/熟状态建立关联。

当 `生串 A/透明抠图_高保真/素材索引.csv` 存在时，优先按其中的 `product`、`sample`、`angle` 选择真实角度。花束主视觉优先正面或正面补充；左右侧面用于向外放射；上面、下面和反面通常只作形状参考，除非构图视角确实匹配。不要混用同一实物样本的多个角度冒充多串。
