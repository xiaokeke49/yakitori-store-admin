# 人员与组织

这里同时保留两套模板，分别服务不同的人：

- `01_员工档案/员工档案_TEMPLATE.md`：普通全职、兼职或临时员工使用，记录岗位、排班、上岗要求、薪资和必要的工作沟通。
- `01_员工档案/核心成员_TEMPLATE.md`：参与经营或长期共担结果的核心成员使用，记录分工、权限、阶段成果、薪资或分成和重要约定。

两者不是级别高低，而是合作方式不同。一个人只选择更符合实际合作关系的模板，不需要两份都填。

工作表现不强制套用 KPI：普通员工写岗位应稳定做到的标准；核心成员写未来 1—3 个月要共同实现的阶段成果。

现有谢奥科、袁成、符攀三份资料暂按“核心成员卡”保留，最终归类待老板确认。当前私有仓库允许保存已确认的薪资、股权比例和工作约定；人员档案不得记录手机号、身份证号、银行卡号、紧急联系人及电话、账号密码或 Token。
