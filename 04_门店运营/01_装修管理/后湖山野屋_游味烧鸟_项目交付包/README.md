# 后湖山野屋 · 游味烧鸟 项目交付包

本资料包整理自项目对话中最后确认的方案逻辑。

## 核心方案

- 外部：临湖木屋、暖光、植物、开放感。
- 正面：左侧花坛与吧台，中部沙发休闲区，右侧展示冰箱与半开放入口。
- 内部板前：客人 → 板前/岛台 → 操作通道 → 师傅背影 → 烧鸟炉 → 后墙设备/酒柜。
- 品牌：不是传统日式居酒屋，而是“湖畔 × 木构 × 炭火 × 夜晚 × 长沙”。
