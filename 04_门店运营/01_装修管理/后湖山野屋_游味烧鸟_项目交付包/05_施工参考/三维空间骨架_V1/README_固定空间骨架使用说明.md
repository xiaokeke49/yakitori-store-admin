# 游味烧鸟｜固定三维空间骨架 V1

## 这套文件解决什么问题

这套白模用于锁定同一空间的尺寸、方向、物体位置和摄影机坐标。后续生成或渲染不同视角时，应先从本白模选定机位，再进行材质与氛围深化，避免吧台旋转、沙发换位、板前穿过中央通道、陈列柜左右跳动等问题。

它是方案沟通级白模，不是施工图。正式施工前仍需现场复尺、设备选型和机电深化。

## 坐标规则

- X 轴：左侧湖景吧台 → 右侧板前厨房。
- Y 轴：正面、湖面与游客视线 → 建筑后侧。
- Z 轴：地面向上。
- 模型单位：米。

任何视角变化都不得改变物体的世界坐标。

## 永久固定的空间关系

1. 左前吧台始终横向，与正立面平行；发光品牌立面朝向建筑外部。
2. 左侧两组沙发始终位于横向吧台后方，不能越到吧台前面。
3. 中央入口通道保持净空，并通向后部圆灯沙发区。
4. 板前始终位于右区，沿前后纵深方向布置，不得横穿中央通道。
5. 板前客席位于柜台左侧；厨房操作区位于柜台右侧。
6. 厨师面向右侧炉具工作、背向板前客人；炉具及后墙设备固定右后。
7. 展示柜是独立设备，固定右前；其后不能凭空增加操作台。
8. 左外边界为连续花坛，不作为入口。

## 文件说明

- `00_离线三维白模查看器.html`：双击即可查看；拖动旋转、滚轮缩放，可隐藏屋架或家具，并可切换九个固定机位。
- `游味烧鸟_固定空间骨架_V1.obj`：通用三维白模，可导入 Blender、SketchUp、3ds Max、Cinema 4D 等软件。
- `游味烧鸟_固定空间骨架_V1.mtl`：OBJ 的分区颜色材质。
- `空间骨架_参数与机位_V1.json`：全部物体坐标、尺寸、类别及摄影机参数。
- `01_俯视空间关系校验.png`：平面坐标校验。
- `02_轴测骨架校验.png`：整体空间骨架校验。
- `03_正面骨架校验.png`：正面主视角骨架校验。
- `04_内部中央机位校验.png`：内部机位遮挡关系校验。
- `build_space_skeleton.py`：参数化生成源文件；修改尺寸后可重新生成全部交付物。

## 九个固定机位

1. 俯视校验
2. 正面主视角
3. 外部左前
4. 外部右前
5. 中央步入
6. 左侧沙发区
7. 板前客席区
8. 后侧向湖
9. 轴测总览

## 仍需现场确认的部分

- 屋架总高度、梁截面、屋面坡度和准确柱网。
- 墙体厚度及左侧湖景开口的准确边界。
- 所有设备型号、散热与检修空间。
- 沙发、单椅、吧椅和台面的人体工学尺寸。
- 板前各道台面的高度，以及炉具排烟、补风和消防条件。

在这些尺寸确认前，V1 只用于统一空间逻辑与摄影机，不用于施工放样。
