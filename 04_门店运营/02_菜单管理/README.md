## 使用规则

- 新增、下架或修改价格时，只更新对应品类文件。
- 未确认的菜名、规格和价格统一标记“待老板确认”。
- 对外发布菜单前，检查对应文件的复核与生效记录。
- 菜单设计原图保留在 `08_品牌与店铺资料/04_菜单与价格/`，不作为最新价格来源。
