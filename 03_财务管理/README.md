# 财务管理

管理收入、支出、预算、现金流、毛利、对账和凭证。原始凭证只读，报表必须标明周期与数据口径。

- [每日财务总览](每日财务总览.md)：每天一行，查看已记录收入、支出、收支差额和缺失情况。
- [财务账本.sqlite3](财务账本.sqlite3)：本地 SQLite 数据库，作为导入数据的唯一正式来源；总览为生成结果。

当前已导入已取得的 2025 年 7—11 月、2026 年 3—6 月总表记录，具体覆盖和待核对事项见每日总览。尚未自动同步，未完成明细对账。

经老板确认，财务账本和每日总览纳入当前私有 Git 仓库版本管理；修改数据后同时更新生成的总览并提交。凭据不入库。
