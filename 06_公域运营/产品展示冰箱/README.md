### 先准备，再拿手机

两个人即可：一人拍摄，一人整理托盘及配合取串。负责人待老板确认，下一次发布前完成，具体日期待确认。手机擦镜头，普通拍照模式、竖幅3:4、1×，打开网格，不先套滤镜或人像虚化。拍完每组放大检查食物是否清楚，提交未压缩原图及拍摄日期。

冰箱：在不耽误出品的空档擦净外侧玻璃，托盘归位，竹签方向理顺；只拍当日真实库存，空盘可以避开取景，不能为了显满制造假库存。先用柜内现有灯和店内光，关闭手机闪光灯，移动自己找反光较少的角度，不为拍摄长时间开柜。取串按实际卫生操作，摄影者不越过操作区。

湖景：提前到真实临湖桌位观察；日落前后、湖面还看得清时试拍，不要求有太阳或晚霞。准备一小盘当天熟串，可加实际提供的饮品；无需满桌。保留真实栏杆、岸线和桌位关系，不靠近危险水边。若逆光使食物太暗，先侧移机位，让太阳离开画面；仍暗时请助手在画外靠食物一侧举白纸作反光试拍，或分开拍食物和湖景。

| 编号/表达目的 | 人站哪里、镜头朝哪里 | 布置、动作与光线 | 交付及验收 | 条件不足怎么拍 |
|---|---|---|---|---|
| B1 整柜：让人看到可以选什么 | 顾客侧靠柜子一端，镜头略高于柜面，沿长边斜向约45°，不要正面拍成一条平线 | 托盘理齐，用柜内现有光；先左后右微移，挑不把自己倒影压在食物上的位置 | 拍3张；画面大部分是柜内食物，柜边不过分倾斜，反光不盖住主盘 | 过道窄就拍半柜；优先清晰整齐，不强求全柜 |
| B2 细节：看清串品形态 | 在顾客侧靠近，镜头略俯拍2—3盘；点前排食物对焦，拍糊就退一点 | 前后盘形成层次，竹签自然朝同方向；不把柜外杂物带入 | 拍3张；前盘清晰、食物颜色真实，亮处不过曝，保留少量柜框交代场景 | 玻璃反光无法避开就换另一盘与角度，不要求开柜 |
| B3 取串：让人代入选串 | 拍摄人固定在顾客侧，员工在实际操作侧；镜头对取串区域 | 员工按正常流程夹起一串，手从侧边进画面，停留自然的一瞬间连拍；另录5秒 | 一组连拍＋1段视频；串品和夹具清楚，手不挡主菜，不为镜头重复不卫生操作 | 高峰不配合时跳过动作，先交B1/B2 |
| H1 一盘串＋湖：交代湖边吃什么 | 坐在背湖一侧的桌边、面向湖，手机略高于桌面；小盘在画面下部，湖面留在中部 | 仅一小盘，饮品在侧后方，不挡湖；优先食物清楚，避免太阳正对镜头 | 拍3张；串品有纹理、湖面可辨，水平线不歪，桌面无杂物 | 食物与湖无法同时拍清，就分别拍近景和湖；不要过度压暗串品换晚霞 |
| H2 拿串＋湖：增加用餐动作 | 坐或站在同一安全桌位，一手拿串从下方入画，另一人用1×拍 | 串离镜头到能清楚对焦的位置，手不横挡整个湖面，连拍自然动作 | 一组连拍；焦点在串上，湖仍能辨认，手与竹签连接自然 | 单人不稳就把串放盘沿拍，或由助手拿串 |
| H3 湖边座位：让人知道坐着是什么感觉 | 从用餐区内部向桌位和湖斜拍，退到桌椅能完整入镜的位置，手机保持水平 | 傍晚天没全黑时拍；有现成桌灯可打开，保留真实空座位，不安排假顾客 | 拍3张；桌椅与湖的真实关系清楚，灯不过曝，湖不死黑 | 桌位被遮挡就换实际可用机位；无晚霞也拍真实阴天环境，不添加天空 |

| 项目 | 执行方法 |
|---|---|
| 人与机位 | 助手站在安全用餐区域托稳食品盘，拍摄者在其侧前方，湖在盘后；手机1×竖拍，镜头略高于串品向下，手从画面下角入镜，不站水边冒险 |

| 构图 | 先让盘与串占下方约一半到三分之二，湖面在中间；拍一张接近参考的大天空版，再拍一张少天空、串更突出的版本 |
| 光线与对焦 | 先找柔和侧光，点前排肉串对焦，放大检查纹理；反差大就侧移或换柔光位置，不盲目压暗曝光。避免强人像虚化切坏竹签边缘 |
| 动作与卫生 | 托盘保持水平，拍摄者改变角度，不让助手倾斜盘子；生串保持正常备料与冷藏流程，提前定机位后短时拍摄，拍完及时回到冷藏流程，避免日晒和反复搬出 |
| 验收与替代 | 交3张原图：盘稳、食物清楚、湖可辨、数量真实。托不稳就把食品盘放在干净稳固桌面，保留一只扶盘的手；不必单手托重盘 |
| 条件与负责人 | 待确认当天备料、托盘及安全机位；负责人待老板确认。作为补充镜头，不替代前述12张基础实拍 |

### 拍完怎么交，怎么选

本轮先交B1、B2、H1、H3各3张，共12张；B3/H2动作有条件再补。人员实拍后按上表核对清晰度、反光、实际商品和现场视线，再确定发布候选。建议先测试一篇“选串后坐湖边”的顺序：B1整柜 → B2细节 → 实际烤制/出炉（有则加） → H1少量熟串 → H3座位；这是待测试方案，不保证互动效果。满桌菜品继续暂停。

## 手机端画幅与Live裁切

默认拍3:4竖图，手机普通拍照模式1×。封面优先让串品、端盘或动作成为大主体；柜内细节靠近拍2—3盘，避免连续用相似整柜全景。湖景作为背景要可辨，但不要为了装下大片天空让食物缩小。

构图时四周留少量余量，重要食物、手和竹签末端不要贴边，便于Live推近裁切。选图后检查起止画面，不能推近后切断主商品。环境全景可以保留横图放后面交代空间，不强行裁成竖图；当前Live脚本固定3:4，横图裁切不合适时另选图或单独处理，不能直接套用。

### 对我们原判断的修正

不是“重复标题、整柜封面就不行”。对方多次使用同一个标题，也有表现好的整柜作品。我们应改的是每篇能否让用户明确看到一个具体卖点，而非为了不同强行换标题。观察到的成片亮度与纹理可借鉴，但灯具、参数、修图方式未知，不猜它用了闪光灯或AI。

| 我们下一轮 | 拍摄/制作方法 | 标题与正文方向 |
|---|---|---|
| 一个在售招牌单品 | 竖3:4近景，2—3串或一盘占大部分画面，侧光照清表面；背景压简洁；选图后制Live | 标题“长沙后湖｜＋实际菜名＋一个具体看点”；正文说真实做法和口感，避免一整段泛化治愈文案；菜名与做法先核对 |
| 端盘生串＋湖 | 按H4执行，以端盘与排列吸引注意，湖面作为本店差异 | 可测试“在长沙后湖边，先挑串，再等开烤”；不是承诺当日景象，素材时效须核实 |
| 整柜陈列 | 保留整柜，但先理托盘和竹签，按可见商品颜色层次布置，避开柜灯强反光；不凭空加库存 | 具体介绍图里两三样实际在售串品；有明确名称/价格才放准确标识 |

评论引导围绕实际画面给可回答的问题，例如两种真实在售串品里更想尝哪一种；问址/问价应直接提供已核实信息，不照搬对方要求先入群的门槛。我们可以用湖景加强到店理由，但不能让湖景取代食物本身的吸引力。

本轮只把结论写在本文件，未新建同行目录或批量下载素材。下方18页拆解是本次模仿策划的依据；前面的12张是基础补拍单，不等于对方的完整发布结构，也不限制我们只能发布少量图片。

### 能确认的制作特点，以及不能冒充知道的部分

1. **先把商品摆出视觉特点，再靠近拍。** 竹签方向、肉片包裹、彩色搭配、重复排列都在拍之前决定了。白底、金属盘和垫纸反复出现，背景简单；没有依靠华丽场景支撑这篇。我们可用现有干净托盘和食品用垫纸，不必先装修或准备满桌菜。
2. **单串、单盘、整柜三个尺度交替。** 单串图看形态，单盘特写看纹理，整柜看选择。5页拼图集中放进许多小画面，再用大特写恢复食欲感。不能把他的内容概括成“18张整柜”或“拍一张好看的图做Live”。
3. **重复有明确对象。** 鸡翅在开头、第7页和结尾数页重复，标题也只点鸡翅；其他商品负责扩展选择。他没有要求每页必须出现全新菜品。同一篇可以把一组已拍的菜品用于拼图和单独大图，但本次未核对原图，不能断言具体哪两页复用了同一文件，也不能断言其跨篇重复率。
4. **成片色彩有连续性。** 熟食的金黄与绿色细丝、生串的红白与绿色/黄色反复出现，食物占画面大部分。只能确认呈现结果；手机型号、闪光灯、灯具、调色参数和是否AI生成均未知。实拍可以先用近距离柔光或侧前方补光测试，白底不过曝、肉与蔬菜颜色不偏色，再调整位置。
5. **正文让人围绕菜品选择说话。** 标题包含城市和具体菜品，正文写脆皮、排列等具体特点，再问想尝哪一种。多品种图片给了读者回答的对象。观察到的作者回复含邀请来吃及入群；我们的问址、问价评论应直接给核实信息，不需照搬入群要求。
6. **Live是呈现层，不能代替商品与构图。** 多页明确显示LIVE，但仅凭网页标识不能判断原生实况、后期推近或其他制作方式。我们已有单图转推近Live能力，可以用于自己的成片；不能宣称与对方制作方式相同，也不能据点赞证明Live带来增长。

这篇在观察时为1813赞、246收藏、60评论。它能支持“这种组合有用户互动”，不能证明图片数量、某一颜色或某个顺序导致高流量；没有曝光、逐页停留、完读及到店数据。另一篇较低互动样本也说明近景和短文案本身不保证效果。
