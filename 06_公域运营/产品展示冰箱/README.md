# 产品展示冰箱

## 项目目标

本项目用于长期记录和发布湖边烧鸟店展示柜内的烧鸟、食材、成串细节以及湖景晚霞实拍图。

以小红书为主要平台，优先发布真实、有场景感的种草图文；抖音作为同步补充平台。内容持续展示食材新鲜、当天现串现用的制作特点，以及舒适的湖边环境和傍晚晚霞，吸引长沙同城顾客私信了解、到店消费。

账号保持“真实店主营业日常”的感觉。种草内容必须以真实门店、真实商品和真实环境为依据，不冒充顾客写虚假体验，不虚构销量、排队、库存、制作时间或顾客反馈，也不承诺发布后一定获得流量。

当前只做展示柜内的烧鸟及食材。以后增加饮品、甜品或其他商品时，先确定新的栏目和规则，不直接混入当前内容。

## 每日工作流程

1. 用户发送展示柜、烧鸟串、湖景晚霞原始实拍图和当天商品信息。
2. 从候选图中挑选2至3张，优先组合“食物细节＋湖边环境”，确认商品清楚、画面真实、没有明显重复。
3. 对选中图片做轻度美化，并保留原图用于对比。
4. 先准备小红书种草文案和音乐建议，再根据同一组真实信息改写抖音文案和音乐建议。
5. 交付完整发布预览，由用户核对图片、价格、文案、音乐和发布时间。
6. 只有收到用户明确的“确认发布”后，才能操作平台发布。
7. 默认在每天12:00至14:00发布，后续根据账号后台数据调整。
8. 发布完成后保存平台、发布时间、作品链接和所用素材记录，避免重复发布。

## 每天需要用户提供的内容

发送图片时，尽量同时提供以下信息：

- 原始实拍图，不要先压缩、套滤镜或加平台水印。
- 展示柜、烧鸟串、湖景和晚霞照片可以分开拍摄，但要说明各自的拍摄日期。
- 商品名称；不确定的商品可以直接注明“不确定”。
- 拍摄日期，说明是当天拍摄还是之前保存的照片。
- 当天是否执行“食材新鲜、当天现串现用”；如有特殊情况需要主动说明。
- 当前库存情况，例如“有货”“少量”“售完”或“不确定”。
- 固定价目表是否发生变化。
- 当天是否有不能发布的商品、画面或信息。

可直接复制下面的格式：

```text
拍摄日期：
当天照片 / 历史照片：
主要商品：
包含的画面：展示柜 / 烧鸟串 / 湖景 / 晚霞
当天是否现串现用：是 / 否 / 不确定
库存情况：
价格是否变化：没有 / 有，变化内容是：
不能出现的信息：
希望发布时间：默认12:00至14:00 / 其他：
```

如果商品、价格、库存或拍摄时间没有可靠信息，不根据图片猜测，也不擅自补写。

## 选图与图片顺序

一次发布优先使用2至3张照片：

1. 第一张：从烧鸟串特写、晚霞湖景或展示柜全景中选择最能让人停下来的真实画面，第一眼体现“湖边吃烧鸟”的特色。
2. 第二张：展示当天主推烧鸟、现串过程或新鲜食材细节，为“食材新鲜、当天现串现用”提供画面依据。
3. 第三张：补充湖景晚霞、舒适座位、展示柜丰富度或真实门店氛围，让顾客能想象到店体验。

如果只有两张合格照片，不为了凑数重复使用相似画面。优先保留一张烧鸟或食材图和一张湖景环境图。第一张不使用模糊、反光严重、主体被遮挡或商品状态不好的照片。

## 图片美化标准

### 可以调整

- 裁切、扶正和轻微调整构图。
- 校正曝光和白平衡。
- 轻微调整亮部、暗部、对比度和饱和度。
- 轻微增加清晰度、降噪，改善拍摄设备造成的画质问题。
- 在不改变商品和现场事实的前提下，处理很小的镜头污点。
- 轻微还原晚霞和湖面的真实明暗与色温，但必须以原图现场效果为准。

### 禁止调整

- 不改变商品数量、大小、形状、配料和摆放关系。
- 不改变商品颜色、熟度、新鲜程度、分量和包装。
- 不修改或虚构标签、价格、日期、库存和活动信息。
- 不增加、删除或替换烧鸟及食材。
- 不添加假热气、假火焰、假顾客、假排队或虚构门店环境。
- 不更换天空、不生成晚霞、不扩大湖景，也不把阴天修成晚霞天。
- 不改变展示柜的真实结构，不把旧柜修成新柜。
- 不使用会让商品出现塑料感、过度油亮、边缘融化或纹理重复的AI效果。

第一批图片先制作一组轻修样张，同时保留原图对比。只有用户明确确认“看不出AI处理、商品没有失真”，才把该强度作为后续图片的标准。只要无法确认商品结构没有改变，就退回原图重新轻修。

## 文案规则

### 共同原则

- 口吻像店主在记录真实营业，不写成生硬广告。
- 开头直接写湖边晚霞、烧鸟串、展示柜或顾客能获得的真实到店体验。
- 一次只突出一个重点，不把多个无关卖点塞进同一篇。
- 文案中的商品名、价格、库存、制作时间和门店信息必须有依据。
- 门店固定卖点可以写“食材新鲜、当天现串现用、湖边环境舒适、傍晚可以看晚霞”，但只能写真实存在并有照片或门店资料支持的内容。
- 结尾只设置一个主要行动，例如“想看菜单可以私信”或“晚餐想吃烧鸟可以来店里看看”。
- 可以争取浏览、收藏和私信，但不能写“保证爆”“一定上热门”等承诺。

### 小红书（优先）

- 以真实种草文为主，让顾客同时感受到“烧鸟值得吃”和“湖边晚霞值得来”。
- 标题优先包含长沙、湖边烧鸟、晚霞、现串或晚餐等真实可搜索关键词，但一条标题不要堆满所有词。
- 正文先写一个具体场景，再写新鲜食材和当天现串现用，最后补充湖景晚霞与舒适环境。
- 以店主视角记录，不写成“第一次来就爱上了”等虚假顾客口吻。
- 不只写“环境很好、食材新鲜”等空话，要用照片中的串、展示柜、现串过程、湖面或晚霞作为依据。
- 结尾自然引导收藏、私信菜单或到店看晚霞，不强迫关注。
- 使用与内容真实相关的长沙本地、烧鸟、湖景、晚霞和晚餐关键词，不添加无关流量词。

小红书种草文结构：

```text
标题：长沙/湖边烧鸟/晚霞/现串中的1至2个关键词 + 具体看点
开头：一个能代入的湖边晚餐或晚霞场景
食物：食材新鲜，当天现串现用，结合图片写具体串品或细节
环境：湖景、晚霞、座位和舒适感，只写画面或资料能证明的内容
结尾：收藏备选 / 私信看菜单 / 到店看晚霞，三选一
话题：长沙本地 + 烧鸟 + 湖景晚餐 + 本篇实际元素
```

推荐表达示例：

```text
傍晚坐在湖边等晚霞，手边再来几串刚烤好的烧鸟，这顿晚餐会慢下来。
店里的食材当天准备、当天现串现用，柜里有什么就拍什么，不做过度修图。
想看当天菜单可以私信，遇上好天气还能一起看湖边晚霞。
```

### 抖音（同步补充）

- 从小红书内容中提炼一个最强画面或卖点，重新写成短、直接、口语化的文案，不整篇复制。
- 优先突出长沙同城、湖边晚餐、当天现串现用和展示柜里的主推商品。
- 第一行要能单独成立，让顾客不听音乐也能明白内容。
- 根据真实内容使用少量相关话题，不堆砌无关热门词。

抖音文案结构：

```text
第一句：烧鸟串、湖景晚霞或当天现串中的一个真实钩子
第二句：商品或到店场景补充
结尾：私信或到店行动引导
话题：长沙同城 + 烧鸟/湖景晚餐 + 实际画面元素
```

## 当天照片与历史照片

历史照片可以发布，但采用不带具体日期的常青文案。

- 可以写：“展示柜装满的时候，看着就很有食欲。”
- 可以写：“晚餐不知道吃什么，可以看看柜里这些烧鸟。”
- 不写：“今天刚上柜”“今日现做”“今晚只剩这些”等无法由当前信息证明的话。

即使历史照片中的商品现在仍在售，也要按照当前价目表和库存重新核对后再写价格或库存。

历史晚霞照片可以用于表达门店真实的湖边环境，但不能写成“今天的晚霞”。历史烧鸟照片可以说明门店长期坚持当天准备、当天现串现用，但不能把照片中的商品说成当天现有库存。

## 价格规则

- 固定价目表必须由用户提供并确认。
- 只有商品名称与固定价目表准确匹配时，文案才能带价格。
- 价目表发生变化后，以用户最后确认的版本为准。
- 商品识别不清、名称不匹配或价格有疑问时，不猜价格，统一改为“具体可以私信了解”。
- 发布预览中要标明本次价格来自哪一版价目表，确保可以追溯。

## 背景音乐规则

- 每次分别从抖音、小红书当时可用的正版曲库中推荐音乐。
- 音乐优先符合湖边、烟火气、轻松晚餐和真实营业氛围。
- 不为了追热点使用与画面情绪明显冲突的音乐。
- 不从不明来源下载音乐，不把一个平台下载的音乐直接搬到另一个平台。
- 发布前再次确认歌曲仍可使用；不可用时更换同类氛围音乐并重新给用户确认。
- 图片、文案和音乐建议必须一起交付，收到确认后才能发布。

## 发布前检查

- [ ] 抖音和小红书账号处于正确的登录状态。
- [ ] 选用的是本次确认的2至3张图片，顺序正确。
- [ ] 美化后商品结构、数量和颜色与原图一致。
- [ ] 晚霞和湖景来自真实照片，没有换天、扩景或过度增艳。
- [ ] 商品名称、库存和价格都有可靠依据。
- [ ] “食材新鲜、当天现串现用”的表达符合门店实际执行情况。
- [ ] 历史照片没有冒充当天拍摄或当天上柜。
- [ ] 门店名称、地址和营业时间来自已确认资料。
- [ ] 小红书已按种草文完成，抖音已重新提炼，没有机械复制。
- [ ] 推荐音乐在对应平台仍然可用。
- [ ] 没有其他平台水印或无法确认来源的素材。
- [ ] 已收到用户对完整发布包的“确认发布”。

## 异常情况处理

### 当天实拍图

按正常流程处理，可以写当天信息，但“现做”“刚上柜”等表述仍需用户明确确认。

### 历史照片

使用常青文案，不写具体拍摄日期，不冒充当天营业状态；价格和库存必须重新核对。

### 价目表缺失或价格不匹配

不写价格，改为私信了解，并在发布预览中标记“价格待补”。

### 商品识别不清

不猜商品名、不猜配料；先向用户核对。无法及时确认时，改写为不点具体商品名的真实场景文案。

### 平台音乐不可用

在同一平台正版曲库中重新推荐同类氛围音乐，重新获得确认后再发布，不能擅自换歌。

## 项目验收标准

每次最终发布包必须同时满足：

- 商品结构和现场状态与原图一致。
- 图片经过轻度美化，但看不出明显AI处理痕迹。
- 晚霞、湖面和环境保持实拍状态，没有虚构或过度美化。
- 文案没有虚构商品、日期、价格、库存、销量或顾客反馈。
- 小红书种草文同时呈现新鲜现串的食物卖点和湖景晚霞的环境卖点，并有真实素材支撑。
- 历史照片没有冒充当天照片。
- 所有价格都能追溯到用户确认的固定价目表。
- 小红书为优先平台并采用真实种草表达；抖音根据同一素材重新改写。
- 音乐来自对应平台可用曲库并经过用户确认。
- 未收到“确认发布”时，不进行发布操作。
- 发布完成后可以查到对应链接和素材记录。

## 当前边界

本项目目前只建立内容制作和确认发布规则，不包含自动发布程序。完成账号登录条件、固定价目表和门店资料核对后，再单独规划自动发布；即使以后实现自动操作，也继续保留“用户确认后才能发布”的规则。
