# 插花基础课程导航

## 这门课怎么学

这是一门从零开始的8周插花入门课，不是素材收藏夹。每周4课，每课约60—90分钟，理论约占1/3，实操约占2/3。

你只需要按编号学。学完一课，完成文件最后的练习；学完一章，把作业照片发给我点评。

## 学习时间

- **4周，约18—24小时：**达到入门。能看懂基础构图和配色，能模仿做出简单插花作品。
- **8周，约36—48小时：**达到基础毕业。能独立完成一款基础商业花束，并说清构图、配色和固定逻辑。
- **12周以上：**通过反复打样，开始具备稳定制作商业产品的能力。

你的目标是以后对外售卖高端烧鸟花，所以建议完整学完8周，不在第4周刚入门时就开始设计售卖产品。

## 完整8周教学大纲

### 第1章｜认识插花

1. 插花、花艺与花束
2. 花材的六种角色
3. 新手工具与操作安全
4. 第一次观察和分类作业

### 第2章｜花材处理

1. 识别花材的自然姿态
2. 修剪、去叶、醒花与储存
3. 长度、角度、朝向与开放度
4. 花材加工与基础实操

### 第3章｜构图审美

1. 点、线、面、块与空间
2. 比例、尺度、平衡与重心
3. 主次、焦点、层次与视觉路径
4. 高低、前后、疏密、节奏与留白

### 第4章｜色彩与质感

1. 色相、明度、纯度和冷暖
2. 同色、邻近、对比与互补配色
3. 主色、辅色与点缀色的面积关系
4. 花材、叶材、花器和包装的质感

### 第5章｜底座与固定

1. 花泥的浸泡、切割和固定
2. 剑山、胶带网格、鸡笼网与枝条支撑
3. 作品重心、底面和受力
4. 固定结构的隐藏与搬动测试

### 第6章｜基本花型

1. 半球形
2. 三角形与扇形
3. 直立式与倾斜式
4. 不对称自然花型

### 第7章｜手绑花束与包装

1. 螺旋手法与手握点
2. 单面花束与四面花束
3. 外轮廓、层次与花束自立
4. 包装纸层次、收腰与丝带

### 第8章｜风格与毕业作品

1. 中式、日式、西式与现代花艺
2. 韩式、法式、英式花园和现代简约风格
3. 从参考图到配方、草图和成品
4. 毕业作品与100分评审
