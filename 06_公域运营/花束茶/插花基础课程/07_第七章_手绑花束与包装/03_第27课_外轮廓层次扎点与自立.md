# 第27课｜外轮廓、层次、扎点与自立

## 1. 外轮廓

先确定花束是圆形、椭圆、自然不对称还是扇面。边缘叶材和线条花材负责“画边界”，但外轮廓不应像剪纸一样僵硬，可保留少量自然伸出。

## 2. 顶部层次

花束顶部至少存在前、中、后和高、中、低变化。主花组可相对集中，小花和叶材向外过渡。不要把所有花头压成一顶平帽。

## 3. 扎点

扎点位于稳定的螺旋交叉区。过高会挤压花头、花束不开；过低会使上部松散、花材滑动。扎紧后轻摇花束，单支花不能明显下滑。

## 4. 自立测试

将扎点以下花茎修剪为相近长度并放到平面上。花束能够自立，说明螺旋方向和底部支撑基本正确；无法自立时检查是否有反向花茎、长度差过大或重心偏移。

自立只是结构检查，不代表所有商业花束都必须以站立姿态陈列。

## 综合练习

完成一束15—21支的四面观螺旋花束：

- 至少3种高度；
- 一个主花组群；
- 边缘有空气感；
- 扎点集中；
- 自立10秒；
- 提起轻摇后没有单支下滑。
