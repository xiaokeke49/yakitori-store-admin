# 第06课｜修剪、醒花、养护与储存

## 学习目标

学会根据花材状态处理，而不是套用“所有花都要深水醒花一夜”的固定流程。

## 1. 收花后先检查

1. 拆掉外包装，但严重脱水的花头保护网可暂时保留。
2. 挑出断头、霉变、异味或大面积腐烂的花材。
3. 清洗水桶，去掉桶内残留叶片和黏液。
4. 判断是否明显脱水：花头下垂、花茎发软、叶片萎蔫才需要加强补水。

## 2. 通用修剪

- 去掉会浸入水中的叶片和侧枝；
- 去掉腐烂、霉变、破损部分；
- 用锋利剪刀一次剪断，不来回挤压花茎；
- 普通草本花茎可斜剪约2—3厘米；木本枝条根据粗细平剪、斜剪或作辅助切口；
- 不熟悉的花材不随意用火烧、开水烫或加家用药物。

## 3. 什么时候需要醒花

长途运输后明显脱水的花材，可在修剪后放入较深的清洁水中补水，花头一般保持在水面上，置于阴凉、无直射光处。花材本身状态良好时，正常修剪和水养即可，不必为了“走流程”长时间深水浸泡。

不同花材需求差异很大，正式使用前要向供应商确认具体品种的水位和处理方法。

## 4. 日常养护

- 水质发浑、有异味时立即换水；
- 换水时清洗花器和花茎黏液；
- 复剪底部老化切口；
- 及时去掉枯花和黄叶；
- 远离暖气、空调出风口、直射阳光和成熟水果；
- 使用鲜花保鲜剂时按产品标注比例，不凭感觉过量添加。

## 实操与达标

选同一批花材6支，记录收到时的花头、花茎和叶片状态。分为正常水养组和需要补水组，2小时后对比，写下“为什么这样处理”。能根据状态做决定，而不是对所有花套同一流程，即为达标。
