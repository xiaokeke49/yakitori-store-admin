## 使用顺序

1. 先读目标串品 README 的固定骨架与禁改项。
2. 选择真实样本与角度，优先真实合成；AI只补不可见边缘、光影与轻微形变。
3. 同束同款串使用不同样本或不同角度，禁止镜像复制。
4. 按验收清单放大检查；未通过的图片不得当作真实商品图发布。
