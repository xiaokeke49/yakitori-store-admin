# 彩椒牛肋条｜串品视觉档案

> 用途：为“游味烧鸟”花束设计、AI 概念生成、真实素材合成和最终质检提供视觉约束。
>
> 样本范围：A、B、C 三根真实生串，每根包含正面、反面、左右侧面、上面和下面，共 18 张照片。
>
> 重要边界：本档案记录的是照片中能观察到的形态规律，不等于已确认的厨房标准配方。涉及固定克重、精确尺寸和门店出品规范时，仍需负责人确认。

## 1. 串品身份

- 名称：彩椒牛肋条
- 状态：生串
- 主体：不规则切块或折叠的牛肋条
- 配菜：较厚的彩椒片
- 竹签：一根扁平浅色竹签，从食材厚度中心附近贯穿
- 视觉特征：红色牛肉与红、黄或绿色彩椒形成高饱和间隔，是花束中适合承担主视觉的串品。

## 2. 三个样本共同出现的结构

以下为 A、B、C 三根实物均能观察到的共同点：

1. 每根均呈现约 **4组牛肋条肉块**。
2. 肉块之间穿插约 **3段彩椒**。
3. 总体节奏为“肉—彩椒—肉—彩椒—肉—彩椒—肉”，而不是把肉和彩椒分别堆在两端。
4. 彩椒不是薄纸片，具有明显厚度、弧度和果肉面；部分边缘向前或向后翘起。
5. 牛肉不是规则方块。肉块会折叠、塌陷、偏斜，左右宽度不一致。
6. 竹签大致经过各食材的中央厚区，但实际穿刺点存在轻微偏心，不是机械居中。
7. 食材之间多数相互挤压，局部存在窄缝；不是完全等距，也不是紧密压成一整块。

### 当前可信度

- “4肉＋3彩椒、交替排列”在三个样本中重复出现，暂列为**高可信视觉骨架**。
- 这仍只是三根样本的观察结果。如果厨房实际允许其他数量，应由门店补充规则后修改。

## 3. 三根实物之间的真实变化

### 样本 A

- 彩椒颜色节奏：红—黄—红。
- 肉块整体偏宽，部分呈扁平折叠状。
- 顶部和中下部能看到较明显的浅白脂肪带；底部肉块纹理较复杂。
- 正面轮廓中段略向右突出，底部肉块宽而不完全对称。
- 侧面可见红椒与黄椒有不同倾斜角度，并非平行切片。

### 样本 B

- 彩椒颜色节奏：红—黄—红。
- 上端肉块带较明显脂肪层，中段肉块更厚、更团聚，下端相对偏瘦。
- 黄色彩椒呈弧形，露出面积比 A 更大。
- 肉块之间的间隙与挤压程度不均匀，右侧和左侧轮廓差异明显。
- 反面比正面更紧凑，说明肉块具有折叠和包裹关系，不能简单复制正面纹理到背面。

### 样本 C

- 彩椒颜色节奏：黄—绿—黄。
- 肉块整体比 A、B 更修长，正面层次更松。
- 中央绿色彩椒只露出较窄的一段，部分被相邻牛肉遮挡。
- 上下两段黄色彩椒的宽度、弧度和露出方向不同。
- 肉块肥瘦分布不平均：部分偏瘦红，部分边缘带浅色脂肪。

## 4. 生成时必须保持的“不变量”

1. 串品身份必须清楚：牛肋条与彩椒交替，不能变成肉丸、肉饼、培根卷或鸡肉块。
2. 默认沿用观察骨架：约 4组牛肉、3段彩椒，交替穿串。
3. 彩椒必须夹在肉块之间，不能漂浮、贴在肉表面或凭空长进肉里。
4. 每段食材只能由同一根竹签连续贯穿；竹签不能忽粗忽细、断裂、分叉或从错误方向穿出。
5. 生串必须保留生肉颜色、湿润感、脂肪和肌理，不能出现焦边、炭纹、熟化收缩或刷酱光泽。
6. 肉块需要保留不规则切面、折叠和轻微受压形变，不能全部变成相同大小的圆润模块。
7. 肥肉应呈乳白至浅粉的半透明组织，并和红色瘦肉自然连接；不能画成纯白塑料条。

## 5. 可以变化的范围

同一花束出现多根彩椒牛肋条时，必须制造有依据的差异，但不得改变产品身份。

### 允许变化

- 彩椒组合可参考实拍使用红—黄—红或黄—绿—黄。
- 肉块宽窄、厚薄、折叠方向和边缘缺口可以不同。
- 单根串可偏肥、均衡或偏瘦，但同一肉块内部的肥瘦连接必须自然。
- 彩椒露出面积、弧度、倾斜方向和被肉遮挡的程度可以不同。
- 食材总体长度、局部间距和轮廓左右偏移可有小幅差异。
- 花束中可以有轻微前后旋转；不同串不应全部正面朝向镜头。

### 不允许变化

- 不得把第二根串直接复制第一根，仅改变缩放或镜像。
- 不得随意增加、减少或重新排序食材，除非门店另行确认出品规则。
- 不得让三段彩椒颜色、形状和角度完全相同。
- 不得让四块牛肉拥有重复的纹理、高光、脂肪位置或外轮廓。
- 不得为了“好看”把牛肉修成规则立方体或统一厚度。
- 不得把红椒误生成番茄、胡萝卜或香肠；黄椒和绿椒也必须保留彩椒果肉与表皮特征。

## 6. 肉质与表面细节

### 瘦肉

- 主色从深红、鲜红到粉红变化，不应整根只有一个红色色值。
- 表面可见细小肌理、切割形成的方向纹和局部凹凸。
- 边缘常有轻微撕裂、薄片或折角，不是光滑圆角。
- 正对强光的湿润部位会出现小面积高光，但高光位置不应在所有肉块上重复。

### 脂肪

- 以不连续的浅白、乳白或浅粉带状、块状分布出现。
- 有些脂肪贴着肉块边缘，有些夹在瘦肉内部；不是每块肉都具有相同脂肪比例。
- 强光下脂肪亮度明显高于瘦肉，但仍保留组织层次和微弱颜色。

### 彩椒

- 外皮较亮，切面和果肉较哑；同一片彩椒不能全表面均匀发亮。
- 边缘有自然弧度和厚薄差，部分切面会出现颗粒感或细小水分反光。
- 彩椒受肉块挤压后可能略微弯曲，但不能软化成融化胶片。

## 7. 角度应该怎样使用

- **正面**：确认肉和彩椒的排列节奏、主要肥瘦纹路和花束主展示面。
- **左/右侧面**：确认真实厚度、彩椒翘起方向、肉块折叠和前后遮挡；用于花束两侧内倾摆放。
- **反面**：确认正面看不到的脂肪、折叠和穿刺关系，防止生成背面仍复制正面纹理。
- **上面/下面**：确认竹签进入食材的位置、肉和彩椒的真实厚度；主要用于结构理解，不建议直接作为花束主视觉。

花束摆放建议：

- 中心主串优先采用正面或轻微三分之二侧面。
- 左侧串应选择能向花束中心内收的角度，右侧串使用相反方向。
- 同时出现 A、B、C 时，应保留三者各自肥瘦和颜色区别，不统一修成同一种标准模型。

## 8. 光线变化规律

本组照片主要为近距离强闪光环境，因此可观察到：

- 正对闪光灯的生肉明显更亮、更粉，湿润高光更强。
- 侧面和背光面颜色更深，红色更沉，纹理对比下降。
- 脂肪在强光下接近乳白，在侧光下会回到浅粉或灰粉。
- 彩椒表皮会产生集中亮点，切面通常更柔和。
- 竹签受光面偏黄白，背光边缘偏棕；不能整根保持同一亮度。

生成晚霞花束时不能直接照搬闪光灯效果。需要保留上述材质差异，同时把主高光方向改为符合晚霞或补光灯的方向；否则会产生“背景逆光、食材正面被棚拍灯打亮”的明显合成感。

## 9. 花束中的视觉角色

- 推荐角色：中心主串、次中心高位串、强色彩焦点。
- 推荐理由：红色牛肉与黄、红、绿彩椒具有强对比，能在粉白、奶茶、黑色或牛皮纸包装中快速被识别。
- 同束建议数量：通常 1–3 根即可。是否增加应由整体构图决定，不为了展示品类强行加入。
- 多根同时出现时：优先混用 A、B、C 的变化逻辑，一根偏肥、一根偏瘦；一根红黄、一根黄绿；高低和朝向也应不同。

## 10. 可直接用于图像生成的约束摘要

```text
彩椒牛肋条必须保持游味烧鸟真实串法：约4组不规则牛肋条与3段厚切彩椒交替穿在一根扁平竹签上。牛肉存在真实的肥瘦差、切面、折叠、挤压和不对称边缘；彩椒具有厚度、弧度、表皮与切面差异。多根同款串必须各不相同，可参考红-黄-红与黄-绿-黄两类颜色节奏，并改变肥瘦、宽窄、折叠、间距、角度和遮挡，但不能改变交替串法、食材身份或竹签贯穿关系。禁止肉丸化、规则方块化、复制纹理、统一高光、塑料脂肪、彩椒融化、竹签断裂或凭空穿出。生串不得出现焦边、熟化、炭纹或刷酱。
```

## 11. 单串验收清单

生成或合成后逐项检查：

- [ ] 能一眼识别为牛肋条和彩椒，而不是其他肉类或肉丸。
- [ ] 肉和彩椒保持交替关系，数量没有无故变化。
- [ ] 竹签连续、粗细稳定，穿刺位置能在不同角度成立。
- [ ] 四组肉块的轮廓、肥瘦、高光和纹理没有复制。
- [ ] 三段彩椒的颜色、弧度、角度和露出面积不是完全一致。
- [ ] 肥肉与瘦肉连接自然，脂肪没有变成纯白塑料。
- [ ] 生肉湿润但不过度发亮，没有均匀油膜或刷酱感。
- [ ] 光线方向与花束背景一致，暗部和接触阴影存在。
- [ ] 多根同款串之间有真实差异，而不是镜像、复制或简单缩放。

只要出现肉丸化、串法改变、重复纹理、竹签错误或生熟状态错误，即判定不合格，不进入发布候选。
