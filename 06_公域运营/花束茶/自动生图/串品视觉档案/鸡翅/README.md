# 鸡翅｜串品视觉档案

> 用途：为“游味烧鸟”花束设计、真实素材合成、AI补全和发布前质检提供单品约束。
>
> 样本范围：A，共 5 张实拍。文中数量均是当前照片的视觉观察，不等于已确认的厨房克重或永久配方。

## 1. 一眼识别

- 两段带骨鸡翅部位沿单签纵向串起，保留翼段的关节、皮面和渐细轮廓。
- 视觉角色：结构感强，适合侧方或中位增加真实烧鸟辨识度。

## 2. 当前照片中的固定骨架

- 上下两段之间有可见分界；每段均非规则块，厚端与薄端由骨骼结构决定。
- 竹签必须连续穿过实际食材厚区，前后角度能互相解释；不能断裂、分叉、忽粗忽细或凭空穿出。
- 生串保留原始湿润度、切面和组织颜色，不出现焦边、炭纹、熟化收缩或刷酱高光。

## 3. 材质与光线

- 黄色鸡皮有毛孔，粉色肉与白色软骨在切口处自然相连。
- 原片多为近距离强光：正对光源处更亮、湿润高光更集中，侧背面更暗且饱和度下降。合成到晚霞或门店场景时，应重新统一光向、色温、阴影和颗粒，不能保留孤立闪光灯白斑。
- 保留细小瑕疵、压痕、切口和轻微色差；不要全局磨皮、锐化或让每一处都同样清晰。

## 4. 同款多根时怎样变化

- 两段的弯曲、皮面朝向、骨端露出、大小和间距应不同。
- 多根同款不得由一张抠图镜像、缩放或复制纹理得到；优先混用真实样本和不同角度。
- 高低、前后、旋转角度可以变化，但不能借变化改变串法和食材身份。

## 5. 禁改项

- 禁止普通鸡块、无骨圆柱、相同双段、烤熟焦纹或额外翅尖。
- 不得根据名称擅自补出照片中没有的食材、酱汁、装饰或熟制效果。
- 不得让相邻食材穿模、漂浮、融合；接触处应有轻微挤压和接触阴影。

## 6. 花束使用建议

- 结构感强，适合侧方或中位增加真实烧鸟辨识度。
- 正面或轻微三分之二侧面用于主要展示；左右侧面用于花束两翼内收；背面、上面和下面主要用于校验厚度及穿刺关系。
- 单束是否使用、使用几根，以整体美观和产品预算为准，不要求为了展示素材而全部塞入。

## 7. 可复制生成约束

```text
鸡翅必须以游味烧鸟实拍为造型依据。两段带骨鸡翅部位沿单签纵向串起，保留翼段的关节、皮面和渐细轮廓。固定结构：上下两段之间有可见分界；每段均非规则块，厚端与薄端由骨骼结构决定。材质：黄色鸡皮有毛孔，粉色肉与白色软骨在切口处自然相连。同束出现多根时必须产生真实差异：两段的弯曲、皮面朝向、骨端露出、大小和间距应不同。禁止：禁止普通鸡块、无骨圆柱、相同双段、烤熟焦纹或额外翅尖。保持生串状态、竹签连续、接触阴影真实，并使光向与场景一致。
```

## 8. 发布前验收

- [ ] 第一眼能识别为本串品，而不是形近的肉丸、香肠、豆腐或其他蔬菜。
- [ ] 串法、食材数量感、顺序和双签/单签关系与实拍一致。
- [ ] 同类食材没有复制轮廓、纹理、高光、脂肪或籽粒。
- [ ] 竹签贯穿关系成立，遮挡、挤压和接触阴影自然。
- [ ] 生熟状态正确；材质不呈塑料、蜡、橡胶或3D模型感。
- [ ] 花束内高低、朝向、疏密有节奏，但串品没有被重新设计。
- [ ] 背景与串体的光向、色温、景深、噪点和清晰度一致。
- [ ] 放大检查没有多余食材、重复器官、融化边缘或畸形竹签。
