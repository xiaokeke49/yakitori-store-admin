# 小美街头娱乐题库

适用对象：“小美”指年轻女性受访者，不预设她是大学生，也不限制职业、学历、是否长沙本地人或来长沙多久。受访者类型是“小美”，不代表观众只有女生；题目必须让不同年龄和性别的普通观众都能听懂、参与和评论。

拍摄玩法：每位受访者回答三道题，原则上按照“简单热身 → 人物或长沙相关 → 反差或轻逻辑挑战”组合。答题和送花是吸引观众继续看的内容入口，不是视频最终目的；后续要自然带出湖景、烧鸟烤制、熟串出品和真实试吃。每题只按“标准答案”和“可接受答案”判奖，“拍摄点/评论点”不参与判分。

## 一、现场统一规则

1. 不设置固定答题时间，根据受访者的反应灵活推进；有趣的犹豫、讨论和笑点可以多保留，明显冷场时及时提示或换题。
2. 每位受访者独立完成三道题，同行不参与答题、不提醒、不抢答，也不替受访者提交答案。
3. 同行如果也愿意参加，就在上一位结束后重新单独拍摄三道题，作为另一期内容；一期只以一个人为答题主体。
4. 同义表达符合“可接受答案”即可判对，不要求逐字一致。
5. 题目有争议或主持人口误时，该题不判错，立即更换备用题。
6. 热梗、影视、明星和音乐题上线前重新核实；过期题移入暂停区。

8. 长沙美食里，你觉得哪一种最容易被外地人低估？
9. 如果获得一束烧鸟花，你会先拍照还是先吃？
10. 今天这三道题，哪一道最容易让人下意识答错？

## 八、出题和更新检查

- [ ] 每题只有一个明确标准答案，并写好可接受答案。
- [ ] 评论点与判奖答案已经分开。
- [ ] 三题难度能逐步上升，不连续使用三道计算题。
- [ ] 题目不依赖美妆、医学或其他专业术语，普通观众听一遍就能理解。
- [ ] 没有评价受访者身材、外貌、年龄、感情经历或消费能力。
- [ ] 热梗、明星、歌曲和节目事实已经在发布前重新核实。
- [ ] 现场备有至少两道同难度替换题。
- [ ] 拍摄结束后记录实际答题率和节目效果，低质量题暂停使用。
