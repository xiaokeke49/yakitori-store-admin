# 卖花小男孩｜自动剪辑规范

## 一、默认前提

- 用户提交剪辑任务时，默认已经包含完整街访、到店、端菜、试吃和真实评价素材；缺少到店素材不列为日常询问项。
- 素材由用户提供，不生成不存在的人物、回答、进店过程、奖励或评价。
- 门店每天营业均为当天现切现穿，作为已确认的固定经营事实使用，不再逐期询问。
- 黄金三秒、背景音乐、答题音效和基础美颜由自动剪辑负责，不在开工前逐项询问用户。

## 二、奖励识别规则

| 有效答题数 | 奖励 |
| --- | --- |
| 0题 | 无奖励 |
| 1题 | 价值不低于38元餐品 |
| 2题 | 价值不低于58元餐品 |
| 3题 | 价值不低于88元餐品 |

- 花束题说出名字、花语和原因即为有效；缺少其中一项则不计。
- 后两题只有答案符合标准答案或可接受答案才计为有效。
- 没答出来的题从故事中快速跳过，可保留一个真实表情和“跳过”衔接，不反复堆叠失败片段。

  "consent_record": "口头授权素材或联系方式记录",
  "flower_answer": {

    "meaning": "花语",
    "reason": "原因",
    "completed": true
  },
  "quiz_questions": [

      "accepted_answers": ["标准答案", "可接受答案"],
      "answered_correctly": true

    {"name": "餐品名", "quantity": 1, "menu_price": 0}

## 四、自动处理顺序

1. 使用ffprobe检查画幅、帧率、音频和文件可读性。
2. 使用本地中文转写生成带时间戳文本，并区分主持人与答题女生。
3. 按一位答题女生一条视频划分素材，同行三人只进入该女生的试吃辅助镜头。
4. 删除“第一题、第二题、第三题”等提示话术、无关聊天、重复提问和无信息长停顿。
5. 未答出的题保留最短必要过程后直接跳到下一题。
6. 从笑容、意外回答、犹豫、获奖反应和第一口评价中生成黄金三秒候选，按表情清楚、原声完整、画面无遮挡、能形成悬念的顺序选择。
7. 依次组装黄金三秒、规则、花束题、两道客观题、奖励、进店、端菜、试吃和评论收口。
8. 生成口语化中文字幕，纠正识别错字但不改变原意。
9. 对女生画面执行轻度降噪、提亮和肤色统一，不修改五官或脸型。
10. 自动匹配轻松、节奏不过密的背景音乐；优先使用已授权本地曲库或原创配乐。
11. 人声出现时对背景音乐自动压低，停顿和转场处适度恢复；答对使用轻快确认音，未答出使用克制落空音。
12. 输出9:16、1080×1920、H.264/AAC发布预览和剪映导入包。

## 五、自动阻断与警告

仅在以下情况停止生成“可发布版”：

- 视频损坏、音轨不可读或主要回答完全无法听清；
- 无法区分答题主角，可能把两位女生或两组采访混在一起；
- 没有公开发布授权记录；
- 奖励结果与实际答题数明显矛盾，继续剪辑会制造虚假结果。

以下情况不再阻断：

- 某一道题没有答出来：直接跳过并按有效答题数计算奖励；
- 没有单独的烤制镜头：项目本来就不拍烤制过程；
- 没有逐期核实“当天现切现穿”：这是门店每天营业的固定真实流程；
- 用户没有指定黄金三秒或背景音乐：由自动剪辑根据素材与整体节奏决定。

收到的素材若意外缺少到店、端菜或试吃段，不编造内容；仍可生成检查预览，但标记为“素材异常”，不称为完整发布版。

## 六、交付与验收

每次输出：

- 完整预览MP4；
- 剪映可导入的分段素材；
- ASS/SRT字幕；
- 剪辑时间点和使用素材清单；
- 自动选择的背景音乐、音量策略和音效记录；
- 质量检查结果。

验收必须确认：黄金三秒来自真实素材、人物无遮挡、题目与结果一致、奖励档位正确、背景音乐不压人声、字幕安全、真实评价未被篡改、最终MP4可从头到尾播放。
