# 视频脚本目录说明

本目录用于存放“湖边街访答题赢到店烧鸟”账号的单期视频脚本。

脚本必须以项目根目录的 [`README.md`](../README.md) 为总执行标准，围绕以下完整故事展开：

> 路人亮相 → 三道题 → 获得到店奖励资格 → 自愿进店 → 现场烤熟并兑现 → 湖边环境和产品展示 → 真实试吃 → 观众互动

## 一、文件命名

建议每期单独创建一个 Markdown 文件：

```text
第001期_人物或核心看点.md
第002期_人物或核心看点.md
```

示例：

```text
第001期_长沙女生挑战三道题.md
第002期_大叔挑战湖南历史题.md
```

如有对应素材，可在本目录下建立同名文件夹，但原始视频素材不要重复复制，脚本中记录真实素材路径即可。

## 二、每期脚本必须包含

1. 本期定位：人物、地点、奖励、预计时长和核心看点。
2. 黄金三秒：真实爆点画面、人物原声和屏幕文字。
3. 三道题：题目、标准答案、可接受答案、难度和判分结果。
4. 现场流程：开场邀请、答题、反应、判分和奖励说明。
5. 进店流程：走向门店、湖景、烤制、入口和真实评价。
6. 结尾互动：给观众留下一个能直接回答的问题。
7. 拍摄清单：主镜头、补拍镜头、收音和奖励兑现证据。
8. 剪辑备注：开头候选、保留反应、字幕重点和节奏要求。
9. 结果记录：实际答题、是否进店、是否兑奖及真实反馈。

## 三、固定创作原则

- 视频以受访者为主体，拍摄者采用第一视角，原则上不出镜。
- 开头直接使用本期最有吸引力的真实反应，不先做背景介绍。
- 保留真实笑声、犹豫、停顿、回答和评价，不要求统一话术。
- 三道题按照“容易进入—稍有思考—形成记忆点”排列。
- 判分只依据标准答案和事先写明的可接受答案。
- 奖励必须进店后现场烤熟、现场兑现；不进店则不发放。
- 产品和湖景服务于人物故事，不把街访剪成生硬广告。
- 不虚构答题结果、进店过程、顾客评价或门店经营数据。

## 五、完成状态

- 脚本写完，只代表完成拍摄方案。
- 拍摄后应补写实际答题、兑奖、进店和试吃结果。
- 用户要求“剪出成片”时，需要检查真实素材和剪映工程，并导出可播放视频；不能用脚本代替成片。
- 只有完成画面比例、声音、字幕安全区、明显静音和播放检查后，才能标记为“已经验证”。
