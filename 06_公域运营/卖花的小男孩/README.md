# 烧鸟花街头答题赢到店烧鸟——短视频项目执行手册

## 一、项目定位

这是一个围绕“湖边街访答题赢烧鸟串”展开的短视频账号。

拍摄者采用第一视角，不抢受访者的画面。我们在湖边邀请路人回答三道题，根据答题结果获得对应的到店烧鸟奖励；受访者自愿进店后，门店再现场烤熟并兑现奖励，同时拍摄湖景、烧鸟制作和真实试吃反馈。不进店则不发放奖励。

账号不是单纯做街访，也不是单纯展示美食，而是把以下内容串成一条完整故事：

> 路人亮相 → 三道题 → 获得到店奖励资格 → 自愿进店 → 现场烤熟并兑现 → 湖边环境和产品展示 → 真实试吃 → 观众互动

## 二、账号长期原则

### 1. 内容目标

- 好看的女生和真实笑容可以吸引注意，但不能只依赖外貌。
- 根据不同受访者选择不同题目，让视频覆盖年轻人、女生、大叔和普通游客等不同人群。
- 答题过程要有娱乐性，也要有一点知识含量或讨论空间。
- 奖励必须真实兑现，不能为了剧情虚构答题结果或经营效果。
- 进店试吃承担产品展示作用，但不能拍成生硬广告。

### 2. 人物是主体

- 视频整体以受访者为主，第一视角拍摄者原则上不出镜。
- 保留受访者真实的笑声、犹豫、停顿、回答和评价，不要剪得像背台词。
- 谁说话，麦克风就朝向谁；麦克风本身不要长时间挡脸或抢画面。
- 奖品、花束、食物和同行伙伴都是辅助元素，不能盖过受访者。
- 尊重不愿出镜或不愿进店的人，不强行邀请，不用冒犯性问题制造效果。

### 3. 真实比统一话术重要

- 可以问“你觉得味道怎么样”“最喜欢哪一串”，但不要强迫顾客统一说“好恰”。
- 对方说出真实感受后，再顺势介绍食材、部位、烤法或口感。
- 不虚构排队、爆单、顾客评价、销售数据或挑战结果。

## 三、每期固定结构

### 1. 黄金三秒

开头必须直接放本期最能留人的真实画面，不先介绍背景。

- 如果受访者是女生，并且素材中有自然、好看的笑容，优先截取约两秒放在最前面。
- 没有合适的笑容时，从答错、犹豫、反转、爆笑、意外答案或有讨论度的回答中选一个爆点。
- 开头画面、人物说的话和屏幕文字要表达同一件事，不能各讲各的。
- 不为了“黄金三秒”泄露全部答案，要给观众留下继续看的理由。

开头字幕示例：

- “长沙人能连续答对这三题吗？”
- “最后一道题，她的答案把我问住了。”
- “答对三题，湖边烧鸟直接送。”

### 2. 三道题街访

每位受访者固定回答三道题，整体按照“容易进入—稍有思考—形成记忆点”的顺序安排。

1. 第一题：以花束为题，取名以及花语，为什么？
2. 第二题：与湖南或长沙有关，增加内容辨识度。
3. 第三题：略有难度或容易产生评论，让观众也想回答。

三道题不必分别属于三个类别，但整组题至少要满足以下一个方向：

- 有娱乐性；
- 与长沙或湖南相关；
- 有明确答案，同时容易引发观众参与和评论。

### 3. 奖励兑现

- 清楚拍到答题结果、宣布奖励和真实交付过程。
- 奖励统一为进入门店后现场烤熟、现场试吃的烧鸟串或烧鸟花，不在街头直接发放。
- 拍摄前先说清规则，不能在答完后临时改变标准。
- 对方不愿意或不方便进店时，尊重对方并自然结束拍摄，但不发放烧鸟串、烧鸟花或对应奖励。
- 不能用奖励强迫对方进店；街访开始前就要明确说明“答对后需要到店才能领取和食用”。

### 4. 进店试吃和产品展示

受访者愿意进店时，按照以下顺序拍摄：

1. 从街访位置走向门店的简短过渡。
2. 湖边环境和座位视角。
3. 新鲜食材、烤制过程和出品近景。
4. 受访者拿串、入口和第一反应。
5. 询问真实评价，再由店主补充产品信息。

店主介绍要短，例如：

- “这串用的是新鲜鸡腿肉，肉会更厚一点。”
- “这一串火候会偏嫩，外面有焦香。”
- “坐这里吃，正好能看到湖边夜景。”

### 5. 结尾互动

结尾优先让观众参与，不做过长的宣传：

- 把第三道题留给观众回答。
- 问“这三题你能答对几道？”
- 问一个长沙本地讨论题。
- 邀请观众留言下一期想看哪类人、哪类题。

## 四、人物与题型匹配

### 女生

适合轻松、好回答、容易产生真实反应的内容：

- 脑筋急转弯；
- 生活常识；
- 长沙吃喝玩乐；
- 年轻人熟悉的影视、音乐和网络话题；
- 没有冒犯性、观众愿意参与的无选项口头题；正式题不提供二选一或三选一答案。

不要默认女生只能回答娱乐题。现场发现对方对历史、体育或其他领域熟悉，可以顺着她的兴趣调整。

### 大叔及年长受访者

适合大众熟悉、具有基本知识含量的内容：

- 毛泽东、周恩来等大众熟悉的历史人物；
- 湖南历史和长沙地理；
- 常见历史常识；
- 具有年代记忆、但答案能够明确判断的话题。

避免冷僻年份、生僻人物、学术争议和纯靠死记硬背的题。

### 帅哥及年轻潮流受访者

适合年轻人和长沙本地潮流内容：

- 长沙说唱和 C-BLOCK 等本地音乐话题；
- 长沙地标、商圈和年轻人常去的地方；
- 流行音乐、街头文化和本地生活；
- 能引发年轻观众评论，但答案仍然明确的问题。

涉及艺人、歌曲、组合成员或时事时，出题前必须核实信息，避免把网络传言当答案。

### 普通路人或暂时无法判断类型的人

优先使用低门槛通用题：

- 脑筋急转弯；
- 长沙基础常识；
- 日常生活判断题；
- 大众文化常识。

先用第一题观察对方反应，再决定后两题是否需要提高或降低难度。

## 五、题目质量与判分标准

每道题在拍摄前必须写清以下内容：

- 题目原文；
- 标准答案；
- 可以接受的同义说法或简称；
- 难度；
- 适合哪类受访者；
- 为什么适合拍摄或可能引发评论。

判分只依据“标准答案”和“可接受答案”。“为什么适合拍摄”只能用于选题，不能用来临时改变判分。

以下题目不得使用：

- 答案不唯一，却被包装成唯一答案的题；
- 过度冷门、只能靠猜的题；
- 容易攻击年龄、外貌、职业、地域或个人隐私的题；
- 没有可靠依据或已经过时的题；
- 现场无法公平判断对错的题；
- 为了让人答错而故意使用歧义表述的题。

## 六、门店卖点

视频中根据现场情况自然展示，不要一次性把所有卖点念完：

1. 湖边环境漂亮，适合约会、朋友聚会和拍照。
2. 烧鸟使用新鲜食材，肉量足，能够拍出真实的烤制和入口质感。
3. 门店属于中端烧烤定位，重点不是低价，而是环境、食材和体验的平衡。
4. 顾客整体氛围较好，但不要用“顾客素质都高”等容易引起误解的绝对表达。

## 十、剪辑原则

### 开始剪辑前

- 先检查真实素材、剪映工程和素材引用是否完整。
- 不因为工程目录看起来为空，就直接判断没有素材；同时检查剪映素材库和常用导入位置。
- 先找到本期人物最有吸引力的真实反应，再确定黄金三秒。
- 明确哪些镜头是必保留内容：三道题、关键反应、判分、奖励兑现、试吃和门店卖点。

### 剪辑过程中

- 保证受访者始终是主体，不让食物、花束、同行者或麦克风抢戏。
- 保留有价值的犹豫、笑声和真实反应，删除无信息的长停顿。
- 字幕使用口语化中文，纠正明显错字，但不要篡改受访者原意。
- 题目、回答和答案揭晓要让第一次观看的人也能理解。
- 产品镜头要服务于答题奖励和试吃故事，不插入过长的纯广告段落。

明确要求“剪出成片”时，不能只提供脚本、时间线建议或剪辑方案，必须导出一个可以直接播放的版本。

- [ ] 时长符合发布需求，整体节奏没有明显拖沓。

- [ ] 人声清楚，左右声道正常，整体音量没有忽大忽小。
- [ ] 已检查明显静音、断音、爆音和过长空白。
- [ ] 字幕没有超出安全区域，没有被平台按钮或底部标题遮挡。
- [ ] 三道题的题目、回答、判分和奖励结果表达清楚。
- [ ] 奖励交付是真实可见的，不只靠字幕说明。

- [ ] 已从头到尾观看最终导出文件，而不只是检查剪辑时间线。

## 十二、交付状态用语

汇报工作时必须使用准确状态，不能把建议说成已经完成：

- **只是建议**：只提供了脚本、选题、时间点或剪辑方案，没有修改工程，也没有导出视频。
- **已经完成**：已经实际修改文档、工程或生成视频文件，但还没有完成全部检查。
- **已经验证**：已经检查最终文件，并核对时长、比例、声音、字幕安全区、明显静音和播放情况。

如果剪映时间线没有成功写回，应明确说明；独立导出的成片不能被描述成“剪映工程已经写好”。

## 十三、单期最低完成标准

一条视频至少应该让观众清楚看到：

1. 受访者是谁，以及本期最有吸引力的真实反应。
2. 三道题分别是什么、对方如何回答、最终答对几道。
3. 奖励规则和真实兑现过程。
4. 烧鸟产品或烧鸟花的实际画面。
5. 湖边门店的环境优势。
6. 受访者真实的试吃感受，或未进店时合理结束故事。
7. 一个观众可以直接参与回答或评论的问题。
